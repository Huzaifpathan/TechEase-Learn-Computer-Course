# TechEase – Learn Computer Course App

TechEase is an Android-based learning application designed to help users
learn computer fundamentals from basic to advanced levels in a simple,
structured, and user-friendly manner.

The app is suitable for beginners, students, and anyone looking to
build strong foundational computer knowledge.

---

## 🚀 Features
- Structured computer learning modules
- Separate activities for each topic
- Simple and clean user interface
- Easy navigation between lessons

---

## 🛠️ Tech Stack
- Java
- XML
- Android Studio
- Gradle

---

## 📱 Modules Included
- Computer Fundamentals  
- Excel Basics  
- Computer Networking  
- Internet & Security  

---

## ▶️ How to Run the Project
1. Clone the repository:
https://github.com/Huzaifpathan/TechEase-Learn-Computer-Course.git

2. Open the project in Android Studio
3. Let Gradle sync complete
4. Run the app on an emulator or physical device
